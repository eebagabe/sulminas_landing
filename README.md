# SulMinas Laticínios (proposta de site)

Site institucional focado em captação de leads. React + Vite + react-router.

```bash
npm install
npm run dev
```

Deploy: Vercel (preset Vite). `vercel.json` faz o fallback das rotas para `index.html`.

Os formulários não têm backend: a proposta abre o WhatsApp comercial com os dados preenchidos e o contato SAC/Comercial abre o cliente de email.
